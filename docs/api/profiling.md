# Profiling (ODE parameters)

`fdatools.profiling`: generalized profiling estimation of ordinary differential
equation parameters (Ramsay, Hooker, Campbell & Cao 2007). `ODEModel` wraps a
right-hand side, `ProfiledODE` / `profile_ode` fit states and parameters, and
`cstr_model` / `fitzhugh_nagumo_model` are built-in examples.

::: fdatools.profiling
