# PyTorch layers

`fdatools.nn`: differentiable `BasisLayer` and `SmoothingLayer`, and the
`FDataDataset` for `torch.utils.data.DataLoader`. This module needs the
optional extra: `uv add "fdatools[torch]"`. `import fdatools` does not import
PyTorch; `fdatools.nn` is loaded on first use.
