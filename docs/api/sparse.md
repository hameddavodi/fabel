# Sparse data (PACE)

`fdatools.sparse`: functional PCA for sparse or irregular longitudinal data
(PACE, Yao, Müller & Wang 2005). `sparse_mean` fits the mean from pooled
points, `sparse_cov` fits the covariance surface from within-curve
cross-products, and the `PACE` estimator gives harmonics, eigenvalues and
conditional-expectation scores.

::: fdatools.sparse
